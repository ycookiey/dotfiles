# 外に出る日本語の規則

当てる範囲: 外に出る文章だけ(人に送る文・サイトやアプリの画面の文言・人と共有する文書・メール)。ユーザー本人に向けた返事には当てない。

攻めた規則として置く。合わない場面が出たら、規則のほうを直す(例外を足して守らないことはしない)。

1. ぼやけた動詞を使わない: 「見る」「並ぶ」「扱う」「行う」「対応する」「なる」は何をするかを言わない → 「比べる」「数える」「足す」「同率になる」のような具体的な動作の語にする
2. 指示語で前の語を指さない: 「その」「これ」「それ」「そこ」は使わず、名詞を繰り返す
3. 一度使った呼び名を最後まで変えない: 同じ意味の語を混ぜない(「1位」と「上」、「手順」と「段」)。新しい呼び名は初めて使う所で何を指すか書く。説明の中に、説明される語そのものを使わない
4. 比べるときは向きまで書く: 「合計で比べる」ではなく「合計が多いほうを1位にする」
5. 読み手が補える途中の段階は書かない: 「A なので B なので C」の B が自明なら消す
6. 相手の言ったこと・すでに共有したことを繰り返さない: 了解の返事は「了解」だけ。こちらから足すことがあるときだけ書く
7. 決まっていないことを決まったこととして書かない: 相手の了承がまだなら、提案か質問の形にする
8. 自分で作った番号・記号の書き方を使わない(例: 「1-〇」)。番号が要るなら、相手がすでに使っている番号だけ
9. 日本語と英数字の間にスペースを入れない: AI時代、2人、5つ、10/24のEXPO。フォームへの入力・送るメッセージも同じ(hook `ja-ascii-space-reminder` が知らせる)
10. カギかっこは画面の表記と発言の引用だけに使う: 強調や用語の囲みには使わず、地の文で書く(自然と資本が強くなる)。1文に何組も並べない(hook `ja-kagi-overuse-reminder` が知らせる)
