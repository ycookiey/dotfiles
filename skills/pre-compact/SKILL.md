# pre-compact

会話の context を圧縮する前に、**文書化** と **compact 起点メッセージの特定** を行う。

## compact とは

Claude Code には会話履歴を要約して context を圧縮する仕組みがある。

- **Summarize up to here**: 指定メッセージ以前を要約。以降のメッセージは無傷で残る
- **Summarize from here**: 指定メッセージ以降を要約
- 操作方法: `Ctrl` をダブルクリック → メッセージ一覧が表示 → 矢印キーで対象メッセージ選択 → メニューから `Summarize up to here` を選ぶ
- カスタムプロンプト: 要約時に「これは必ず残す」等の指示を渡せる

**リスク**: 要約には抜けが出る。具体的な prop 名/色値/API 引数/採用経緯等の細部は失われやすい。だから事前に **文書化** で永続化する。

## ワークフロー

### Step 1: 会話メッセージ一覧を取得

```bash
~/.claude/skills/pre-compact/list-messages.sh
```

出力は user 発言のみの番号付き一覧 (sidechain は除外)。番号は `Summarize up to here` の起点指定に使う。

### Step 2: 文書化判定と実行

会話を遡り、**未文書化かつ後で必要になる情報** を抽出して docs に保存。

文書化対象の典型:
- **仕様/設計判断**: 採用案 + 不採用案の理由、API シグネチャ、データモデル
- **手順**: 再現に必要な操作シーケンス
- **方針**: 議論経て確定した原則・命名規則

保存先は project の慣習に従う (例: `docs/plan/`, `docs/dev/`, `.claude/docs/`)。既存ファイルに追記できるなら追記、新規必要なら新規作成。

文書化済の情報 (compact で失っても docs から復元可能) と、context に残しておきたい直近作業 (compact ラインより後ろに残るもの) を切り分ける。

### Step 3: compact ライン候補を3つ提示

| ラベル | 意図 |
|---|---|
| 推奨 | 文書化と合わせて最もバランス良く圧縮できる起点 |
| 広め | より多くを圧縮 (文書化で十分カバーできる範囲なら有効) |
| 狭め | 直近の細部を多く残す (文書化漏れリスクを下げる) |

各候補は **メッセージ番号 + 冒頭テキスト** で提示する (ユーザが UI 上で矢印キー選択する際の目印になる)。

### Step 4: カスタムプロンプト (必要なら)

要約に特に残したい情報がある場合、カスタムプロンプトを生成して `clip.exe` で clipboard にコピー:

```bash
echo "要約時に以下を必ず残す: ..." | clip
```

不要なら clipboard コピーはスキップし「カスタムプロンプト不要、デフォルトで実行」と明記。

### Step 5: 操作手順を提示

最終出力に必ず含める:

```
操作手順:
1. `Ctrl` をダブルクリック
2. 表示されるメッセージ一覧で、矢印キーで #N (推奨候補) のメッセージを選択
3. メニューから `3. Summarize up to here` を選択
4. プロンプト入力欄に clipboard の内容をペースト (コピー済の場合) / そのまま実行 (不要の場合)
```

## 出力フォーマット

```
[文書化済]
- <path>:<行> (新規 | 更新) — 概要
- ...

[compact 候補]
推奨   #N  「冒頭テキスト...」  — 採用理由
広め   #M  「冒頭テキスト...」
狭め   #L  「冒頭テキスト...」

[カスタムプロンプト]
(clipboard にコピー済 | 不要)

[操作手順]
1. Ctrl ダブルクリック
2. 矢印キーで #N を選択
3. `3. Summarize up to here`
4. (プロンプトがあれば) ペーストして実行
```

## 注意

- **文書化は省略しない**。compact のみの提案は不可
- 推奨ラインの起点はユーザ発言。番号は `list-messages.sh` の出力に対応
- 「広め」「狭め」を出す際、その境界が文書化済情報のカバー範囲と整合するように選ぶ
- 直近のタスク進行中の context (具体修正履歴、未確定の検討) は基本的に **残す** 側に倒す
