# AI生成典型構文 / 予告→凡庸 / 心理誘導 / 具体性なし断定

観点(4)(13)(14)(15) の詳細と、AI生成典型構文の回避例(表)。

## (4) AI生成の典型構文

- 自己言及: 「本稿は〜論じる」「本論で扱う」「以下、〜する」
- 形式的命名宣言: 「便宜的に〜と呼ぶ」「〜と位置付ける」「(以下〜)」
- 中庸結語: 「〜うる」「〜だろう」「〜とも言える」「〜と読める」「〜と読み直せる」「〜ことが多い」「〜とは限らない」「価値あり」「~として有力」
- 二項対比反復: 「Aではなく Bである」「普遍主義 vs ナショナリズム」。実測では人間中央値1.5%に対しAI 8.3%。文全体の3%を超えたら要注意
- メタファー結語: 鏡, 触媒, 縮図, 逆照射, 手掛かり, 材料
- 律儀すぎる補足: 初出全員フルネーム+著作カッコ, 英語フルスペル併記
- 疑問文→自答の構造(ドラマチック): NG「なぜ○○のか。本書は△△としています。」OK 淡々と理由を述べる
- プレゼン口調の聴衆投げかけ: 「~と思われるかもしれません」は学術発表で過剰
- 二重表現の冗長修飾: 「直接引用」→「引用」、「フルタイトル」→「タイトル」
- 評価的意訳の禁止: 引用元 `quoted as saying` を「名言」と訳すと過剰。中立的に「発言」
- 「~と。」のような体言止め未満の終わり: →「~ということです」のような完結形に
- 「~させられる」の曖昧表現(受身か可能か不明): 能動の可能形なら「~することができる」と明示
- 定型締め・あいさつ(文書内で残るもの): 「参考になれば幸いです」「いかがでしたでしょうか」「知らないと損する」「裏ワザ」→ 削除。「素晴らしい質問ですね」等はチャット応答専用で文書には現れないため対象外
- 一般論導入定型: 「近年〜」「昨今〜」「今日の〜において」「〜が求められています」→ 具体年+具体事実から書き始める
- ステップ表記の機械的定型: 「ステップ1:」「STEP 2:」→ 番号付きリスト or 接続詞。「まず/次に/最後に」だけの機械的区切りも避け、論理関係を示す接続詞に

## (13) 予告→凡庸の落差

冒頭の予告フレーズと中身のギャップが AI 臭。

- **予告の後が薄い**: 「結論から言うと」「本質は」「実は」「正直に言うと」で始めた後の内容が一般論にとどまる → 予告を外して具体から書き始める
- **煽り予告**: 「ここがポイント」「見逃しがちな」「知らないと損する」「裏ワザ」→ 削除

## (14) 心理誘導・セラピスト構文

読み手の感情を操作するテンプレート。ブログ・SNS・小説で顕著。

- **セラピスト構文**: 「あなたは一人ではありません」「あなたは壊れていない」→ 削除
- **セールス導線**: 不安提示 → 救い提供 → 行動促進 の型 → 削除または解体
- **時系列の型固定**: 朝 → 昼 → 夜、月曜 → 火曜 → の「きれいすぎる」構成 → 重要度・因果・対比など別の切り口で構成
- **共感演出**: 「多くの方にとって〜」「〜と感じたことはありませんか」→ 具体的な状況や体験に置換

## (15) 具体性なし断定(削除で直る範囲)

内容が空の断定を検出。**新情報の追加は skill 対象外**(それは執筆であって推敲ではない)。

- **反論不可能な一般論の水増し**: 「一貫性は重要」「成功には努力が必要」「〜が求められています」→ 削除
- **理由なし断定**: 「○○は重要な取り組みです」だけで理由がない → 削除、または執筆時なら理由を追記
- **共感演出の削除**: 「〜という方も多いのではないでしょうか」→ 削除
- **「彼／彼女」の曖昧併記**: 実在人物なら片方に統一(または名前)。仮想の主体なら「その人」等に

### 素材不足の分岐

段落を読み返すと固有名詞・数値・実例がなく一般論しか言えていない — 原因は書き方でなく素材の不足。この状態では言い回しを変えるループを回しても解決しない。次のいずれかで抜ける:

- **ユーザーに素材提供を求める**: 「この主張を裏づける固有名詞・数値・具体的な出来事はありますか?」と問う。Web検索が使える環境ならユーザー承認の上で調べる
- **削除する**: ユーザーが素材を持っていない/追加を望まないなら、段落丸ごと削除
- **一般論と明示して残す**: 主張が抽象度の高い提言等、一般論のままでよい場合(まれ)は「これは一般論です」を暗黙に受け入れて残す(判断台帳に理由付き「残す」)

**見分け方**: 段落から固有名詞・数値・実例をすべて抜いても文意が変わらないなら、一般論止まりのサイン。素材追加は refine のスコープ外(執筆行為)。判断はユーザーが行う。

## AI生成典型構文の回避例

| Before | After |
|---|---|
| 本稿は〜を論じる | (削除 or 「以下、〜を見る」) ※ただし「以下、〜」も AI 臭 |
| 便宜的に〜と呼ぶ | 命名宣言を本文の流れの結果として最後に出す |
| 〜とも言える | (削除して断定) |
| 〜である以前に〜地続きで語られる | 〜とは限らない。多くはまず〜として現れる |
| Aではなく Bである | 二項対比は最大1回。3箇所以上あれば1〜2箇所を別構文 |
| 〜うる/しうる | (削除して断定 or 「〜できる」「〜になる」) |
| 鏡として機能する / 逆照射する手掛かり | (メタファー結語は禁止。具体動詞へ) |
| 〜と。 | 〜ということです |
| 〜させられる | 〜することができる / 〜される(明示) |
| なぜ〜のか。〜としています。 | 淡々と理由を述べる(疑問→自答を避ける) |
| ~と思われるかもしれません | (削除。淡々と) |
| 「主張: ~」「結論: ~」 | テーマを端的に表す名詞句で見出し化 |
| ラベル = 説明 | ラベルは説明(助詞で繋ぐ) |
| A + B | A と B |
| A × B | A、B を組み合わせる |
| 主なリスク: バイアス | 様々な段階で生じうるバイアスのリスク |
| 報告すべきは X | この判断は、X が報告すべき |
| 第一 / 第二 | 構造化文書なら `1.` `2.`、単一段落の散文なら「まず」「次に」「さらに」「加えて」 |
| 多様な、さまざまな(同一節) | 「幅広い」「多くの」等で対比 |
| 同義語の同段落重複 | 別表現で対比 |
| 2020 年 6 月 / 約 3 年間 / 6 ヶ月 | 2020年6月 / 約3年間 / 6ヶ月(日本語と数字の間の全角/半角スペースは詰める・観点(11)) |
| Web は Next.js で 実装 | WebはNext.jsで実装(日本語と英単語の間の空白は詰める、英単語同士の空白は保持・観点(11)) |
| 500 名 / 3 ヶ国 / 12 ヶ月 | 500名 / 3ヶ国 / 12ヶ月(数字と単位の間は詰める・観点(11)) |
| TypeScript (3 年) / Node.js (BE) | TypeScript(3年) / Node.js(BE)(括弧内英数字だけ・括弧外日本語なら詰める・観点(11)) |
| Xだけでなく、Yも / Xだけではなく、Yでもある | 「X と Y が両立する」または片方に絞る |
| 結論から言うと〜(の後が薄い) | 冒頭に本当の結論を 1 文で置く |
| 本質は〜 / 実は〜 / 正直に言うと〜(の後が一般論) | 予告を外して具体的な内容から書き始める |
| 段落を毎回「以上がポイントです」で閉じる | 各段落の閉じ方を変える |
| あなたは一人ではありません / あなたは壊れていない | (削除、または具体的な行動提案に置換) |
| 朝 → 昼 → 夜の時系列で構成 | 時系列以外の切り口(重要度・因果・対比)で構成 |
