# WezTerm キーバインド

割り当ての定義は `keybinds.lua`。`wezterm.lua` で WezTerm 既定のキー割り当てを無効にしている（`disable_default_key_bindings = true`）ので、ここに載っていないキーは効かない。

## ナビゲーション

| キー | 機能 |
|------|------|
| `Ctrl+Tab` | 次へ（ペイン巡回 → 最後なら次のタブ） |
| `Ctrl+Shift+Tab` | 前へ（ペイン巡回 → 最初なら前のタブ） |
| `Ctrl+1~8` | タブ番号で直接切替 |
| `Ctrl+9` | 最後のタブへ切替 |
| `Alt+←/↓/↑/→` | ペイン移動（左/下/上/右）。`Alt+h/j/k/l` は割り当てず nvim の編集操作用に空けてある |

## タブ

| キー | 機能 |
|------|------|
| `Ctrl+T` | 新規タブ（現在のペインのフォルダを引き継ぐ） |
| `Ctrl+W` | タブを閉じる（確認あり） |
| `Alt+,` | 左 (なければ上) の隣接ペインと入れ替え。辺を共有する隣がなければタブ位置を左へ |
| `Alt+.` | 右 (なければ下) の隣接ペインと入れ替え。辺を共有する隣がなければタブ位置を右へ |

## タブ合成・分離

| キー | 機能 |
|------|------|
| `Alt+M` | 現在のタブの全ペインを左隣のタブの右側に元の順で並べて統合 (幅は均等) |
| `Alt+Shift+M` | 現在のペインを新規タブに分離 |

## ペイン

| キー | 機能 |
|------|------|
| `Alt+D` | 上下に分割（新しいペインは下。現在のペインのフォルダを引き継ぐ） |
| `Alt+R` | 左右に分割（新しいペインは右。現在のペインのフォルダを引き継ぐ） |
| `Alt+X` | ペインを閉じる（確認あり） |
| `Alt+Z` | ペインズーム（トグル） |
| `Alt+S` | サイズ調整モード（`h/j/k/l` で左/下/上/右へ 1 セルずつ調整、`Enter` か `Escape` で終了） |

ペイン移動は「ナビゲーション」の `Alt+←/↓/↑/→`。

## コピー・貼り付け

| キー | 機能 |
|------|------|
| `Ctrl+C` | 選択範囲があればコピー、なければ SIGINT |
| `Ctrl+V` | 貼り付け |
| `Alt+V` | コピーモード（Vim風操作） |

### コピーモード内操作

| キー | 機能 |
|------|------|
| `h/j/k/l` | カーソル移動 |
| `w/b/e` | 単語移動 |
| `0/^/$` | 行頭/行頭(非空白)/行末 |
| `o/O` | 選択範囲の反対の端へ / 同じ行のまま左右の反対の端へ |
| `g/G` | スクロールバック先頭/末尾 |
| `H/M/L` | Viewport 上/中/下 |
| `f/F/t/T` | 文字ジャンプ |
| `;` | ジャンプ繰り返し |
| `Ctrl+B/F` | ページ上/下 |
| `Ctrl+U/D` | 半ページ上/下 |
| `v` | 文字選択 |
| `V` | 行選択 |
| `Ctrl+V` | 矩形選択 |
| `y` | コピー |
| `Enter` | コピーして終了 |
| `Escape/q/Ctrl+C` | 終了 |

## その他

| キー | 機能 |
|------|------|
| `Ctrl+Shift+N` | 新しい窓 |
| `Alt+E` | nvim を新しい窓で開く（現在のペインのフォルダを引き継ぐ） |
| `Ctrl++/-/0` | フォントサイズ 拡大/縮小/リセット |
| `Ctrl+Shift+P` | コマンドパレット |
| `Ctrl+Shift+R` | 設定再読み込み |
| `Ctrl+Shift+L` | デバッグオーバーレイ（Lua の REPL とログ） |
| `Alt+Shift+R` | 前回の WezTerm の窓・タブ・分割ペインと Claude Code の会話を復元 |
| `Enter` | `\r` を送る（Win32 Input Mode でエスケープシーケンスが漏れるのを防ぐ。操作は通常の Enter と同じ） |

## セッション復元

`session_restore.lua`。PC の再起動などで WezTerm が終わったあと、`Alt+Shift+R` で前回の状態を開き直す。

- 窓の大きさ（最大化していたか、またはピクセルサイズ）も保存する。復元では先に窓を最大化またはそのサイズにし、大きさが変わってから分割を作る。大きさが変わらず何も起きないときは、もう一度押すとその場で作る
- 30 秒ごとに、窓・タブ・分割ペインの配置と各ペインのフォルダを `~/.local/share/wezterm/session-snapshot-*.json` に保存（WezTerm のプロセスごとに 1 ファイル、新しい順に 10 個残す）
- Claude Code が動いていたペインは、その会話を `c r <会話 ID>` で再開する（1 ペインごとに 1 秒ずらして起動）
- 会話 ID は Claude Code の SessionStart hook（`claude/hooks/claude-pid-session.sh`）が `~/.local/state/claude-pid-sessions/<pid>.json` に記録したもの。無ければ Claude Code 本体の `~/.claude/sessions/<pid>.json` から取る
- 復元するのは、すでに終了した WezTerm のうち最後に終わったもの（同時に終わったものが複数あればペインが最も多いもの）
- 起動直後の 1 タブ 1 ペインの窓で押すと、その初期ペインは閉じる
- 中身のまだ無い会話（`/clear` 直後など）はシェルだけ開く
- 2 枚目以降の窓も、保存時に最大化していれば最大化する
- どのペインも、開いたらまず保存時のフォルダへ `cd` する（WezTerm に渡したフォルダが使われないことがあるため）。nushell の設定で OSC 7 を有効にしてあり、WezTerm は `cd` 後のフォルダを保存する
- 会話の記録ファイルがあるかは、`~/.claude*/projects/*/<会話 ID>.jsonl` を探して判定する（hook が受け取る記録ファイルのパスは、作業フォルダが変わった会話では実在しないため）
- 復元の約 20 秒後に、会話を再開するはずのペインで Claude が動いているかを確かめる。10 秒後にもう一度確かめても動いていなければ、そのペインのシェルに `c r <会話 ID>` を打ち込んでやり直す。その 20 秒後も動いていなければ通知し、戻すコマンドを `~/.local/share/wezterm/session-restore-failed.txt` に書く
